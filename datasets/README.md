# HMDB Dataset Files

This project expects parsed HMDB-derived dataset files to be placed in this folder.

The dataset files are not committed to Git because they are large. Download them from the external archive listed in the thesis/project documentation.

## Expected parsed files

Place the following files in `datasets/parsed/`:

```txt
hmdb_metabolites.jsonl.gz
hmdb_predicted_msms_spectra.jsonl.gz
hmdb_experimental_msms_spectra.jsonl.gz
